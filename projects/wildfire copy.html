산불 검출 프로젝트

산악 지역 CCTV 영상을 활용한 실시간 산불 모니터링 솔루션

🎯 프로젝트 개요 및 목표

본 프로젝트는 산악 지대에 설치된 CCTV 카메라 영상을 실시간으로 분석하여 산불을 신속하고 정확하게 검출하는 딥러닝 기반 시스템을 개발하는 것을 목표로 합니다.

산불 발생 초기에 이를 감지함으로써 광범위한 피해가 발생하기 전에 조기 진압할 수 있도록 지원합니다.

📍 실시간 모니터링 웹페이지 시연

Live Demo: Off (현재는 서버 비용 관계로 중단된 상태입니다.)

실제 운영되는 모니터링 시스템은 아래 영상과 같이 지도를 기반으로 산불 현황을 표시합니다.

약 500대의 카메라에 대하여 실시간으로 산불을 검출하고, 모델의 출력에 기반하여 CCTV 마커의 색상을 다르게 표시합니다.
산불이 없는 경우 회색으로 표시하고 연기가 감지된 경우에는 노란색(≥ 0.1), 주황색(≥ 0.5), 빨간색(≥ 0.9)으로 표시됩니다.

사용자는 지도상의 마커를 클릭하여 검출 결과와 CCTV 영상 원본을 확인할 수 있습니다.

(영상: 캘리포니아 인근 지역의 CCTV 카메라에서 산불/연기 감지 장면 확인)

⚙️ 서비스 구조

서비스는 크게 네 가지 주요 구성 요소로 이루어져 있습니다:

1. 데이터 파이프라인

미국 산악 지역에 설치된 CCTV 카메라에서 실시간 영상을 수집합니다.

수집된 영상과 메타 데이터는 데이터베이스에 저장됩니다.

2. 딥러닝 모델

Transformer 기반의 경량화된 객체 검출 모델을 사용하여 산불 및 연기를 실시간으로 검출합니다.

모델은 다양한 기상 조건과 시간대에서의 영상 데이터를 활용하여 학습되었습니다.

3. 웹 기반 모니터링 대시보드

검출된 정보를 시각화하여 사용자에게 제공합니다.

지도 인터페이스를 통해 각 CCTV 카메라의 위치와 검출 결과를 직관적으로 확인할 수 있습니다.

4. 지속적인 성능 개선

모델의 성능을 지속적으로 모니터링하고, 새로운 데이터를 반영하여 주기적으로 업데이트합니다.

Human-in-the-loop 파이프라인을 통해 수집한 사람의 피드백과 VLM 기반의 파운데이션 모델들을 활용하여 검출기를 개선합니다.

Python PyTorch AWS EC2/S3

서비스는 핵심 기술 스택, 데이터 파이프라인, 모델 개발, 모니터링 대시보드 및 운영 계획으로 구성됩니다.

핵심 기술 스택 (Core Technology Stack)

Python / PyTorch AWS S3 / EC2 / Kinesis PostgreSQL / NoSQL YOLOv8 / ViT MLOps (Kubernetes, MLflow) React / Leaflet Maps

주요 구성 요소 (Major Components)

1. 데이터 파이프라인

수집 및 스트리밍: 미국 산악 지대 CCTV 영상 데이터를 AWS Kinesis를 통해 실시간으로 수집.

전처리 및 저장: 영상 프레임 추출 후, Human-in-the-Loop를 통한 산불/연기 객체 bounding box 레이블링을 진행. 레이블링된 데이터는 PostgreSQL에 저장.

데이터셋: 약 5만 장 규모의 자체 구축 데이터셋 (Multi-Scale Feature Augmentation 적용).

2. 딥러닝 모델 개발

아키텍처: 낮은 사양의 엣지 환경을 고려한 **YOLOv8 Nano** 기반의 경량화된 객체 검출 모델 채택.

핵심 기법: 먼 거리의 객체 인식률 향상을 위해 **Spatial Pyramid Pooling Fast (SPPF)** 모듈을 최적화하여 앵커 박스(Anchor Box) 미세 조정.

멀티모달 학습: **CLIP 기반 VLM(Vision-Language Model)**을 활용하여 영상 특징과 지역 날씨, 습도 데이터를 통합 학습하여 오탐지율을 **12%** 감소시킴.

3. 웹 기반 모니터링 대시보드

기술 환경: 프론트엔드 **React**, 지도 시각화 **Leaflet Maps API** 사용.

핵심 기능: 검출 결과를 실시간 히트맵(위험도 컬러 코딩)으로 시각화하여 제공. 검출 즉시 AWS SNS를 통한 담당자 자동 알림 시스템 구축.

제어: 지도 상에서 원격 CCTV의 각도 및 줌(Zoom) 제어 기능을 제공하여 현장 상황 파악 지원.

4. 운영 및 확장 계획

지속적인 성능 개선 및 MLOps

MLOps 파이프라인: **Kubernetes와 MLflow**를 사용하여 모델 성능 저하(Data Drift) 감지 시 자동 재학습 및 배포를 유도하는 MLOps 환경 구축.

확장 로드맵: 향후 드론 영상 및 위성 이미지 데이터를 통합하고, 바람 및 지형 데이터 연동을 통한 **산불 확산 예측 모듈**을 추가 개발할 계획.

**개인 기여:** 본 프로젝트에서 **YOLO 모델 경량화 및 MLOps 파이프라인 구축**을 주도적으로 담당함.
